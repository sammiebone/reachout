REACHOUT TROUBLESHOOTING GUIDE

Detailed solutions for common issues.

FRONTEND ISSUES

Application not loading

Check browser console for errors
Press F12 or right-click, select Inspect
Look for red error messages
Screenshot error message
Share with development team

Frontend server not starting
npm run dev fails

npm ERR! code ERESOLVE
npm ERR! ERESOLVE unable to resolve dependency tree

Solution:
npm install --legacy-peer-deps
Or upgrade packages manually
Check Node.js version is 16+

Port 3000 already in use
Error: listen EADDRINUSE :::3000

Solution:
Kill process on port 3000
sudo lsof -i :3000 on Mac/Linux
taskkill /PID <pid> /F on Windows
Change port in vite.config.js

Module not found errors

Module not found: can't resolve 'axios'

Solution:
npm install axios
cd client && npm install && cd ..
Delete node_modules and reinstall
npm cache clean --force

React rendering errors

Blank white page with no errors

Solution:
Check index.html content loads
Verify main.jsx file exists
Check App.jsx is syntactically correct
Clear browser cache
Try different browser

BACKEND ISSUES

Server not starting
npm run server:dev fails

Error: Cannot find module 'express'

Solution:
npm install in root directory
Check package.json is correct
Verify Node.js installed properly
Clear npm cache if needed

Port 5000 already in use
Error: listen EADDRINUSE :::5000

Solution:
Change PORT in .env
Kill process using port 5000
lsof -i :5000 on Mac/Linux
taskkill /PID <pid> /F on Windows

Environment variables not loading

API calls fail with credential errors
Twilio/Gmail API errors

Solution:
Verify .env file exists in root directory
Check .env has no quotes around values
Verify no spaces in .env file
Restart server after changing .env
Check NODE_ENV is set correctly
console.log to verify variables load

Nodemailer authentication failed

Error: Invalid login: 535-5.7.8 Username and password not accepted

Solution:
Verify EMAIL_USER is correct Gmail address
Check EMAIL_PASSWORD is app password, not Gmail password
Regenerate app password in Google account
Enable less secure app access if needed
Verify 2FA is enabled on Gmail account

Twilio authentication failed

Error: Authentication failed with Twilio

Solution:
Verify TWILIO_ACCOUNT_SID is correct
Verify TWILIO_AUTH_TOKEN is correct
Check credentials in Twilio console
Regenerate API credentials if needed
Verify account has active status

COMMUNICATION ISSUES

Emails not sending

Email sent but not received

Check spam/junk folder
Verify recipient email address correct
Check email address format
Look for bounce messages

Email takes too long to deliver

Gmail rate limiting at 300 emails per minute
Implement delays between sends
Check Gmail account restrictions
Verify sending limits not exceeded

SMS not sending

SMS not delivered to phone

Verify phone number includes country code
Check phone number format: +1234567890
Verify phone number is active mobile device
Try adding phone number manually with country code

Only some SMS sending

Some phone numbers work, others don't

International numbers need proper country code
Verify each phone number individually
Check Twilio account has funds
Verify phone numbers in target country supported

SMS delivery very slow

SMS takes over 30 seconds to arrive

Network latency issue
Twilio service delay
Mobile carrier queue
Check Twilio dashboard for status

FORM VALIDATION ISSUES

Email validation failing

Error: Please enter a valid email address

Verify email format is user@domain.com
Check for spaces in email
Verify no special characters except @
Try different email address

Phone number validation failing

Error: Phone number must have at least 10 digits

Remove dashes and parentheses
Enter only digits and country code
Include country code +1
Minimum 10 digits required

Empty message error

Error: Message body cannot be empty

Click in editor area to focus
Type at least one character
Verify text appears in editor
HTML generated should not be empty

DEBUGGING STEPS

1. Check browser console
   Press F12
   Look for JavaScript errors
   Check Network tab for failed requests

2. Check server console
   Look for error messages
   Check request logging output
   Monitor CPU and memory

3. Check logs
   Application logs
   Server error logs
   Email delivery logs
   SMS delivery logs

4. Test individual components
   Test email separately
   Test SMS separately
   Test form validation
   Test editor functionality

5. Verify credentials
   Test Twilio credentials directly
   Test Gmail credentials directly
   Check .env file loaded
   Verify no typos in credentials

GETTING HELP
