REACHOUT DEPLOYMENT GUIDE

PRODUCTION DEPLOYMENT STRATEGIES

This guide covers deploying Reachout to various cloud platforms.

HEROKU DEPLOYMENT

Prerequisites
Heroku account
Heroku CLI installed
Git repository initialized

Steps

1. Create Procfile in root directory
   web: npm start

2. Create .env file on Heroku
   heroku create reachout-app
   heroku config:set TWILIO_ACCOUNT_SID=your_sid
   heroku config:set TWILIO_AUTH_TOKEN=your_token
   heroku config:set TWILIO_PHONE_NUMBER=+1234567890
   heroku config:set EMAIL_USER=your_email@gmail.com
   heroku config:set EMAIL_PASSWORD=your_app_password
   heroku config:set NODE_ENV=production

3. Build and deploy
   npm run build
   git push heroku main

4. Scale workers if needed
   heroku ps:scale web=1

RAILWAY DEPLOYMENT

Prerequisites
Railway account
GitHub repository connected

Steps

1. Connect GitHub repository to Railway
2. Add environment variables in Railway dashboard
3. Set build command: npm install && npm run build
4. Set start command: npm start
5. Deploy automatically on git push

DIGITALOCEAN APP PLATFORM

Prerequisites
DigitalOcean account
App specification file

Steps

1. Create app.yaml in root directory
   name: reachout
   services:
   - name: web
     github:
       repo: your_username/reachout
       branch: main
     build_command: npm install && npm run build
     run_command: npm start
     http_port: 5000

2. Configure environment variables in DigitalOcean UI
3. Deploy through DigitalOcean console

AWS ELASTIC BEANSTALK

Prerequisites
AWS account
AWS CLI configured
Elastic Beanstalk CLI

Steps

1. Initialize Elastic Beanstalk
   eb init -p node.js-18 reachout-app

2. Create environment
   eb create reachout-production

3. Set environment variables
   eb setenv TWILIO_ACCOUNT_SID=your_sid
   eb setenv TWILIO_AUTH_TOKEN=your_token
   eb setenv TWILIO_PHONE_NUMBER=+1234567890
   eb setenv EMAIL_USER=your_email@gmail.com
   eb setenv EMAIL_PASSWORD=your_app_password
   eb setenv NODE_ENV=production

4. Deploy
   eb deploy

DOCKER DEPLOYMENT

Create Dockerfile in root directory

FROM node:18-alpine

WORKDIR /app

COPY package.json package-lock.json ./
RUN npm install

COPY . .

RUN npm run build

EXPOSE 5000

CMD ["npm", "start"]

Build and run
docker build -t reachout .
docker run -p 5000:5000 --env-file .env reachout

Environment Variables for Production

PORT=5000
NODE_ENV=production
TWILIO_ACCOUNT_SID=your_production_sid
TWILIO_AUTH_TOKEN=your_production_token
TWILIO_PHONE_NUMBER=+1234567890
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_app_password

REVERSE PROXY CONFIGURATION

Nginx configuration example

upstream reachout {
  server localhost:5000
}

server {
  listen 80
  server_name api.reachout.com

  location / {
    proxy_pass http://reachout
    proxy_http_version 1.1
    proxy_set_header Upgrade $http_upgrade
    proxy_set_header Connection 'upgrade'
    proxy_set_header Host $host
    proxy_cache_bypass $http_upgrade
    proxy_set_header X-Real-IP $remote_addr
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for
  }
}
