PYTHON SMS-SENDER SETUP GUIDE

This application uses the Python SMS-Sender package for sending SMS messages.

REQUIREMENTS

Python 3.8 or higher
Git
pip (Python package manager)
Node.js 16 or higher

INSTALLATION STEPS

1. Install Python
   Download from https://www.python.org
   Verify with python3 --version
   Recommend Python 3.9 or higher

2. Clone SMS-Sender repository
   git clone https://github.com/farukalpay/SMS-Sender.git
   This creates SMS-Sender directory in project root

3. Install Python dependencies
   pip3 install -r requirements.txt
   Installs requests and python-dotenv

4. Verify SMS-Sender setup
   cd SMS-Sender
   Check that main.py exists
   Review README.md for configuration
   cd ..

HOW IT WORKS

Frontend sends message to backend API
Backend strips HTML to plain text
Backend calls Python SMS service via child process
Python service runs SMS-Sender main.py for each phone number
SMS-Sender connects to SMS gateway and sends message
Results returned to backend
Backend responds to frontend with status

INTEGRATION ARCHITECTURE

Node.js Backend (server.js)
  └─ Spawns Python Process (sms_service.py)
     └─ Calls SMS-Sender (main.py)
        └─ Sends SMS via gateway

PHONE NUMBER FORMAT

Required format for SMS-Sender
Remove all non-digit characters from phone number
Use only numeric digits
Example: 5551234567

The application automatically cleans phone numbers:
+1 (555) 123-4567 becomes 5551234567

TROUBLESHOOTING

Python SMS service not found
Error: SMS-Sender not installed

Solution:
git clone https://github.com/farukalpay/SMS-Sender.git
Verify SMS-Sender directory exists in root
Check main.py file is present

Python not installed
Error: python3: command not found

Solution:
Install Python from https://www.python.org
Add Python to system PATH
Verify with python3 --version

SMS sending fails
Error: Failed to send SMS to all numbers

Solution:
Verify phone number format is correct
Check SMS-Sender configuration
Verify SMS gateway credentials configured
Check internet connection
Review SMS-Sender logs

Process timeout
Error: SMS service timeout

Solution:
Increase timeout in server.js (currently 60 seconds)
Check SMS gateway performance
Reduce number of SMS in single request
Verify network connection

Permission denied error
Error: Permission denied

Solution:
Make sure sms_service.py is readable
chmod +x sms_service.py
Run as user with Python execution permission

Import errors
Error: No module named requests

Solution:
pip3 install -r requirements.txt
Verify requirements.txt has all dependencies
Check Python virtual environment if used

PRODUCTION DEPLOYMENT

When deploying to production server:

1. Install Python on server
   apt-get install python3 (Linux)
   brew install python3 (Mac)

2. Clone SMS-Sender on server
   git clone https://github.com/farukalpay/SMS-Sender.git

3. Install Python dependencies on server
   pip3 install -r requirements.txt

4. Configure SMS gateway on server
   Set up credentials
   Test SMS sending

5. Update server start script
   Ensure Python available in server PATH
   Test full deployment

DOCKER DEPLOYMENT

If using Docker for deployment:

1. Dockerfile must include Python
   FROM node:18 includes node
   Add python installation to Dockerfile

2. Example Dockerfile

FROM node:18-alpine
RUN apk add python3 py3-pip

WORKDIR /app
COPY . .

RUN git clone https://github.com/farukalpay/SMS-Sender.git
RUN pip3 install -r requirements.txt
RUN npm install
RUN cd client && npm install && cd ..

EXPOSE 5000
CMD ["npm", "start"]

5. Run pip3 install -r requirements.txt
6. Test SMS sending
7. Deploy to production
