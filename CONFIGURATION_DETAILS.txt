PYTHON SMS-SENDER CONFIGURATION

SMS_PROVIDER
Type: String
Value: python-sms-sender
Description: Identifier for SMS delivery service
Example: SMS_PROVIDER=python-sms-sender
Importance: Used for logging and tracking

Installation Requirements

Python 3.8 or higher
SMS-Sender package from GitHub
Python dependencies (requests, python-dotenv)

Setting up Python SMS-Sender

1. Clone SMS-Sender repository
   git clone https://github.com/farukalpay/SMS-Sender.git

2. Install Python dependencies
   pip3 install -r requirements.txt

3. Configure SMS gateway
   Follow SMS-Sender/README.md
   Set up API credentials for your SMS provider
   Support for multiple SMS gateways

4. Test SMS sending
   cd SMS-Sender
   python3 main.py <phone_number> <message>
   cd ..

SMS Gateway Configuration

Different SMS providers require different setup
Research SMS-Sender documentation for your gateway
Common providers: AWS SNS, Nexmo, Twilio via SMS-Sender
Configure provider credentials in SMS-Sender config

Gmail CONFIGURATION

EMAIL_USER
Type: String
Format: Valid Gmail email address
Example: myemail@gmail.com
Requirement: Must have Gmail account
Importance: Used as sender address for emails

EMAIL_PASSWORD
Type: String
Description: Gmail app-specific password, not account password
Example: abcd efgh ijkl mnop
Length: 16 characters with spaces
Security: Different from Gmail password
Importance: Critical for email delivery

Setting up Gmail

1. Ensure Gmail account uses 2-Step Verification:
   - Visit myaccount.google.com
   - Click Security in left menu
   - Enable 2-Step Verification if not enabled

2. Generate App Password:
   - Go to myaccount.google.com/apppasswords
   - Select application: Mail
   - Select device: Windows Computer (or your device)
   - Google generates 16-character password
   - Copy all 16 characters including spaces
   - Do not modify the password

3. Add to .env:
   EMAIL_USER=yourname@gmail.com
   EMAIL_PASSWORD=abcd efgh ijkl mnop (with spaces)

4. Test email sending:
   - Use Nodemailer test in code
   - Or send test message through UI

Common Gmail issues

Authentication fails
- Verify EMAIL_PASSWORD is app password
- Regenerate app password if needed
- Confirm 2-Step Verification enabled
- Check correct Gmail address used

Emails go to spam
- Warm up account with low volume
- Implement SPF/DKIM authentication
- Use verified sender domain
- Monitor Gmail feedback loop

Rate limiting
- Gmail throttles at 300 emails per minute
- Implement delays for bulk sends
- Use task queue for high volume
- Monitor account restrictions
