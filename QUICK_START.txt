REACHOUT QUICK START GUIDE

Get your messaging application running in 10 minutes.

PREREQUISITE ACCOUNTS

1. Install Python
   Download from https://www.python.org
   Version 3.8 or higher required
   Verify installation with python3 --version
   Install pip with: python3 -m ensurepip

2. Enable Gmail Access
   Log in to Gmail account
   Go to myaccount.google.com
   Click Security in left menu
   Enable 2-Step Verification if not already enabled
   Go to myaccount.google.com/apppasswords
   Select Mail and Windows Computer
   Copy the 16-character password
   Keep this safe

3. Set Up Node.js
   Download from https://nodejs.org
   Version 16 or higher recommended
   Verify installation with node --version

4. Configure SMS Provider
   Follow SMS-Sender documentation for your SMS gateway
   Get API credentials from your SMS provider
   Set up in SMS-Sender configuration

INSTALLATION

1. Clone or download project
   git clone <your_repo_url> reachout
   cd reachout

2. Clone SMS-Sender repository
   git clone https://github.com/farukalpay/SMS-Sender.git

3. Install Python dependencies
   pip3 install -r requirements.txt

4. Configure environment
   cp .env.example .env
   Edit .env file with Gmail credentials only

   EMAIL_USER=your_email@gmail.com
   EMAIL_PASSWORD=your_16_char_password

5. Install dependencies
   npm install
   cd client && npm install && cd ..

6. Configure SMS-Sender
   See SMS-Sender/README.md for SMS provider setup
   Configure API credentials for your SMS gateway

RUNNING LOCALLY

Start the application
npm run dev

This starts both frontend and backend servers.

Frontend: http://localhost:5173
Backend: http://localhost:5000

USING THE APPLICATION

1. Enter recipient email address
   Format: user@example.com

2. Add phone numbers
   Enter phone number
   Click Add button
   Repeat for multiple recipients

3. Compose message
   Use formatting toolbar for styling
   Bold, italic, underline text
   Add headings
   Create lists
   Change text alignment

4. Send message
   Click Send Message button
   Wait for success confirmation
   Check your email and phone for messages

COMMON ISSUES

Gmail app password not working
Verify 2-Step Verification enabled
Regenerate app password
Check EMAIL_PASSWORD in .env matches exactly

SMS not sending
Verify phone numbers include country code
Check TWILIO_PHONE_NUMBER format
Confirm Twilio account has credits
Verify phone numbers are valid

Port already in use
Change PORT in .env to different port
Or kill process using port 5000
sudo lsof -i :5000 on Mac/Linux
taskkill /PID <pid> /F on Windows

Emails going to spam
Check sender reputation
Add SPF record for domain
Implement DKIM signing
Monitor Gmail feedback
