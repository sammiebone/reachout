PREREQUISITES

GitHub account (free at github.com)
Railway account (free at railway.app)
This Reachout repository pushed to GitHub

STEP 1: PREPARE GITHUB REPOSITORY

1. Create GitHub repository
   Visit github.com
   Click New Repository
   Name: reachout (or your choice)
   Description: Email and SMS messaging app
   Public or Private (up to you)
   Click Create Repository

2. Push Reachout code to GitHub
   cd ~/Downloads/Reachout
   git init
   git add .
   git commit -m "Initial Reachout application commit"
   git branch -M main
   git remote add origin https://github.com/your_username/reachout.git
   git push -u origin main

3. Verify repository
   Visit github.com/your_username/reachout
   Confirm all files uploaded
   Check SMS-Sender submodule (if applicable)

STEP 2: CONNECT RAILWAY

1. Visit Railway
   Go to railway.app
   Click Sign Up or Log In
   Connect with GitHub account
   Authorize Railway access to repositories

2. Create New Project
   Click New Project
   Select Deploy from GitHub repo
   Find reachout repository
   Click Deploy

3. Railway builds application
   Automatically detects Node.js
   Installs dependencies
   May take 2-3 minutes

STEP 3: CONFIGURE ENVIRONMENT VARIABLES

Railway Dashboard

1. Click on your Reachout project
2. Click Variables tab
3. Add environment variables:

   PORT=3000
   NODE_ENV=production
   EMAIL_USER=your_email@gmail.com
   EMAIL_PASSWORD=your_gmail_app_password
   SMS_PROVIDER=python-sms-sender

4. Click Add Variable for each one

STEP 4: CONFIGURE PYTHON AND SMS-SENDER

Create railway.json in root directory:

{
  "buildCommand": "pip install -r requirements.txt && npm install && cd client && npm install && cd ..",
  "startCommand": "npm start"
}

Or create Procfile instead:

web: npm start

Both work on Railway. Procfile is simpler.

STEP 5: HANDLE SMS-SENDER INTEGRATION

Option A: Include SMS-Sender in Repository (Recommended)

1. Add SMS-Sender as git submodule
   git submodule add https://github.com/farukalpay/SMS-Sender.git SMS-Sender

2. Commit changes
   git add .gitmodules SMS-Sender
   git commit -m "Add SMS-Sender submodule"
   git push origin main

3. Railway automatically clones submodule
   Runs pip install -r requirements.txt
   Python SMS-Sender available at runtime

Option B: Clone During Build

Modify Procfile:

web: git clone https://github.com/farukalpay/SMS-Sender.git && npm start

Less reliable but works if submodule not preferred.

STEP 6: BUILD REACT FRONTEND

Create .railway/Dockerfile in root:

FROM node:18-alpine

RUN apk add python3 py3-pip

WORKDIR /app

COPY . .

RUN npm install
RUN cd client && npm install && cd ..
RUN npm run build
RUN pip install -r requirements.txt

EXPOSE 3000

CMD ["npm", "start"]

Or let Railway auto-detect package.json and build scripts.

STEP 7: DEPLOY

1. Push to GitHub
   git push origin main

2. Railway auto-deploys
   Watches main branch
   Automatically builds and deploys on push
   No manual deployment needed

3. Check deployment status
   Railway Dashboard > Deployments tab
   View logs in real-time
   Check for errors or warnings

STEP 8: CONFIGURE DOMAIN

Add Custom Domain

1. Railway Dashboard
2. Click your Reachout project
3. Click Settings tab
4. Add Custom Domain
5. Enter your domain (example.com)

Update DNS Records

If using GoDaddy, Namecheap, etc:

1. Go to domain registrar
2. Find DNS settings
3. Add CNAME record
   Name: @
   Value: railway domain provided by Railway
4. Also add www subdomain
   Name: www
   Value: same railway domain

Propagation

DNS propagation takes 5-60 minutes
Refresh browser after propagation
HTTPS automatic with Railway

STEP 9: VERIFY DEPLOYMENT

1. Visit your domain
   https://yourdomain.com
   Should load Reachout application

2. Test email functionality
   Fill in email field
   Add phone number
   Type message
   Click Send
   Check email for message

3. Test SMS functionality
   Verify SMS-Sender cloned properly
   Check server logs for SMS output
   Verify SMS received on phone

4. Check logs for errors
   Railway Dashboard > Logs
   Look for any error messages
   Python SMS service should appear

TROUBLESHOOTING

Application not loading

Check server is running
View logs for errors
Verify environment variables set
Check port configuration

Build fails

Review build logs in Railway dashboard
Check package.json syntax
Verify Node.js version compatible
Ensure requirements.txt valid

SMS not sending

Verify SMS-Sender submodule cloned
Check Python installed on Railway
Verify SMS gateway configured
Review error logs

Environment variables not working

Ensure variables set in Railway dashboard
Restart deployment after adding variables
Check variable names exact match
Verify no spaces in values

Domain not working

Check DNS records updated
Wait for propagation (60 minutes)
Verify CNAME record correct
Check SSL certificate generated
