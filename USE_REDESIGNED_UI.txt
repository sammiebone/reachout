HOW TO USE THE REDESIGNED UI

Two versions of Reachout are now available. Choose which one you prefer.

QUICK COMPARISON

Original Design
- Gradient purple background
- Generic form layout
- Functional but templated appearance
- Works locally and on Railway

Redesigned UI
- Paper background with structured layout
- Two-column email/SMS channels
- Distinctive, memorable appearance
- Same functionality as original
- Works locally and on Railway

ACTIVATE THE REDESIGNED UI (Local Development)

The redesigned files are alongside originals:

Redesigned CSS: client/src/index_redesign.css
Redesigned App: client/src/App_redesign.jsx

Original CSS: client/src/index.css
Original App: client/src/App.jsx

To switch to redesigned UI:

1. Backup original (optional but recommended)
   cp client/src/index.css client/src/index.css.backup
   cp client/src/App.jsx client/src/App.jsx.backup

2. Switch to redesigned files
   cp client/src/index_redesign.css client/src/index.css
   cp client/src/App_redesign.jsx client/src/App.jsx

3. Restart development server
   npm run dev

4. Open http://localhost:5173
   You'll see the new design

To switch back to original:
   cp client/src/index.css.backup client/src/index.css
   cp client/src/App.jsx.backup client/src/App.jsx
   npm run dev

ACTIVATE THE REDESIGNED UI (Railway Deployment)

To deploy the redesigned UI to Railway:

1. Switch to redesigned files locally (see above)

2. Commit and push to GitHub
   git add client/src/index.css client/src/App.jsx
   git commit -m "Activate redesigned UI with distinctive visual identity

   Co-Authored-By: Claude Haiku 4.5 <noreply@anthropic.com>"
   git push origin main

3. Railway auto-deploys
   Check dashboard for deployment completion

4. Visit your Railway domain
   Should show redesigned UI

WHAT'S DIFFERENT IN THE REDESIGNED UI

Visual Identity
- INK (navy #1A3A4A) for structure and text
- FLAME (rust #E8734F) for secondary actions
- PAPER (off-white #F9F7F3) background
- SIGNAL (teal #2D7A8F) for primary actions and sending

Layout Changes
- Desktop: Two-column layout (Email left, SMS right)
- Mobile: Stacked layout but with clear channel labels
- Message editor sits below both channels
- Send button unites both channels into one action

Typography
- Headers use IBM Plex Mono (monospace) for precision
- Body text uses Inter for readability
- Labels are uppercase with letter-spacing for structure

Interaction Details
- Smoother hover states
- Clear keyboard focus indicators
- Send button shows loading spinner during send
- Reduced motion respected for accessibility

Everything Else
- Same API endpoint (/api/send)
- Same email sending functionality
- Same SMS sending functionality
- Same validation and error handling
- Same responsive behavior on mobile

FUNCTIONALITY UNCHANGED

Both designs send messages identically:
- Email goes to recipient via Gmail
- SMS goes to phone numbers via Python SMS-Sender
- Form validation works the same
- Error messages work the same
- Loading states work the same

DESIGN PHILOSOPHY

The redesign was built around Reachout's core insight:
- Email and SMS are two different channels
- They serve different purposes
- But Reachout sends one message to both
- The design visualizes this duality

The two-column layout makes this clear. The color palette (INK for email formality, FLAME for SMS urgency) represents their natures. The unified send button at the bottom represents sending to both channels as one action.

CUSTOMIZING THE REDESIGNED UI

If you want to modify colors, edit client/src/index.css:

Find the :root section at the top:
:root {
  --ink: #1a3a4a;
  --flame: #e8734f;
  --paper: #f9f7f3;
  --signal: #2d7a8f;
  ...
}

Change any color hex values
Save and refresh browser (npm run dev auto-reloads)

Examples:
- Change --ink to adjust text and structure color
- Change --flame to adjust secondary action color
- Change --signal to adjust primary action color
- Change --paper to adjust background color

All color references throughout the design will update automatically.

FONT CUSTOMIZATION

To change fonts, edit client/src/index.css:

For display/header font, find:
font-family: 'IBM Plex Mono', monospace;

Replace 'IBM Plex Mono' with another monospace font

For body font, find:
font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;

Replace 'Inter' with another sans-serif font

SUPPORT

If the redesigned UI doesn't display correctly:
1. Clear browser cache (Cmd+Shift+R on Mac)
2. Restart development server (Ctrl+C, npm run dev)
3. Check that you copied the right files
4. Verify package.json and vite.config.js unchanged

If you prefer the original design:
1. Restore backup files
2. Restart development server
3. Original design is unchanged
