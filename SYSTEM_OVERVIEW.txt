REACHOUT SYSTEM OVERVIEW

Complete architecture documentation for the email and SMS messaging application.

ARCHITECTURE

Frontend Layer
React 18 with Vite build tool
TipTap WYSIWYG editor for message composition
Axios for API communication
Responsive UI with CSS styling

Backend Layer
Node.js with Express framework
Nodemailer for email delivery via Gmail SMTP
Python SMS-Sender for SMS delivery
CORS enabled for frontend communication

Communication Layer
Email via Nodemailer + Gmail SMTP
SMS via Python child process + SMS-Sender

Database
Not implemented (can be added)
Current design stateless per request
Optional PostgreSQL integration available

DATA FLOW

1. User Input
   User enters email address
   User adds phone numbers
   User composes message with rich text editor

2. Frontend Processing
   Form validation
   HTML content collection from TipTap editor
   API request sent to backend

3. Backend Processing
   Request validation
   HTML to plain text conversion
   Concurrent email and SMS sending
   Response generation

4. Communication
   Email: Nodemailer connects to Gmail SMTP
   SMS: Python process called via child_process
   Results collected and returned

5. Response
   Success status
   Email message ID
   SMS message IDs array
   Error messages if applicable

COMMUNICATION ENDPOINTS

POST /api/send
Purpose: Send email and SMS messages
Request Body:
{
  "email": "string (email address)",
  "phoneNumbers": ["string (phone numbers)"],
  "htmlContent": "string (HTML markup)"
}

Response Success:
{
  "success": true,
  "emailMessageId": "string",
  "smsMessageIds": ["string", "string"]
}

Response Error:
{
  "error": "string (error message)"
}
